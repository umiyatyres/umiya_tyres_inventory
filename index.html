How to connect Google Sheets
  1. Create a Google Sheet and name the tab Stock. The columns are id, vehicle, size, price, shop, and godown.
  2. Open Extensions, then Apps Script. Replace the sample code with sheets/Code.gs. Save.
  3. Choose Deploy, then New deployment, then Web app. Run it as yourself. For access, choose Anyone, not Anyone with a Google account. Copy the link that ends in /exec. Opening that link in a private window should show the stock list, not “Access denied”.
  4. Paste that link above and choose Connect. The site shows only the rows in that sheet. Adding or editing here writes the same rows back.
